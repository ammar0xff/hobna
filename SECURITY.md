# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Hobna, please report it responsibly.

**Do NOT open a public GitHub issue.**

Instead, please email: ammar0xf@gmail.com

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

## Response

- I'll acknowledge receipt within 48 hours
- I'll work with you to understand and fix the issue
- Credit will be given in the fix release (unless you prefer anonymity)

## Scope

- Authentication bypass
- SQL injection
- Remote code execution
- Path traversal
- Cross-site scripting (XSS)

## Out of Scope

- Denial of service
- Social engineering
- Issues in dependencies (report to the dependency maintainer)
